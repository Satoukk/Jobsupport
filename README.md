# JOBサポ

## メンバー

- 佐藤輝三

## アプリ概要

JOBサポは、就職活動に対する不安をやわらげるためのRPG風サポートアプリです。

かわいいキャラクターがユーザーを励ましたり、慰めたりすることで、就活中の不安を軽減します。また、キャラクターが成長する仕組みを取り入れることで、就職活動へのモチベーション維持を目指しています。

## 機能

- ログイン
- キャラクター育成機能
- ミッション
- 企業情報登録

## 使用技術

- React / TypeScript
- Go
- PostgreSQL

## ディレクトリ構成
